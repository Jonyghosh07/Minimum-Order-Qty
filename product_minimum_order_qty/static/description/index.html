Product Minimum Order Quantity

This module allows you to set a minimum order quantity for each product in your Odoo store. It helps to ensure that customers order a sufficient quantity of products, which can be particularly useful for bulk items or products with high shipping costs.

Screenshots And Steps to make it work great

Go to Inventory > Products and select the product you want to set a minimum order quantity for. In the product form, you will see a new field called "Minimum Order Quantity". Enter the desired minimum order quantity for that product.

Now in website customers will not be able to select less than the minimum quantity.

Dependencies
  • product
  • website_sale
